# LinkedIn Post: PDF Tools (HNDIT 4th Semester Project)

🚀 Excited to share my 4th semester project for the HNDIT program: PDF Tools, a full-stack PDF processing web application!

What started as a course project turned into a production-grade platform with 29 tools covering almost everything you'd want to do with a PDF:

📌 Key Features:
🗂️ Organize - Merge, split, remove pages, extract text, reorder with drag & drop, and scan images to PDF
⚡ Optimize - Compress, repair, and OCR scanned PDFs (80+ languages)
🔄 Convert - Word, Excel, PowerPoint, JPG, and HTML to PDF, and back again, plus PDF/A archiving
✏️ Edit - Rotate, watermark, add page numbers, and a full drag-and-drop PDF editor
🔒 Security - Password protect, unlock, and digitally sign PDFs
🤖 AI Tools - Chat-style AI summarizer with auto-generated diagrams, plus PDF translation to 29 languages
🔁 Workflows - Chain multiple tools together into automated pipelines, stored in PostgreSQL

🛠️ Tech Stack:
• Next.js 16 + React 19 + TypeScript
• Tailwind CSS 4 + Framer Motion for a polished, responsive UI
• Clerk for authentication
• Supabase (PostgreSQL + Storage) for the database and large-file uploads
• Stripe for subscription billing
• Adobe PDF Services & iLoveAPI for heavy processing
• OpenRouter for the AI-powered features
• pdf-lib & pdfjs-dist for fast client-side processing
• Inngest background jobs + Upstash rate limiting for reliable, abuse-resistant processing
• Deployed on Vercel

💡 What I learned:
This project pushed me far beyond the classroom. I learned how to design a scalable full-stack architecture, integrate multiple third-party APIs, handle secure file uploads and downloads, implement usage-based billing, and balance client-side vs server-side processing for performance and privacy.

The biggest lesson? Real-world software is about the details. Error handling, edge cases, and user experience matter just as much as the core features.
